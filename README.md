# GVideoCompressor

Простая GUI-утилита на Python для сжатия видео с помощью FFmpeg.

## Как пользоваться

- Для начала, необходимо выбрать видеофайл для сжатия - для этого необходимо либо ввести в соответствубщее поле ввода путь к файлу, либо выбрать файл через кнопку `Обзор`. Также, есть `drag-n-drop`
- При снятом флажке `Пользовательские настройки` используются параметры, подходящие для сжатия видео в целях отправки в мессенджере.
- Имя экспортируемого файла и его расширение настраиваются независимо от флажка. При незаполненном имени, получившийся файл будет иметь имя `<name>_compressed.<ext>`.
- `Перекодированный видеофайл` хранится в директории `оригинального видеофайла`
- Стандартные параметры сжатия: `3000k` видеобитрейт, `128k` аудиобитрейт, `30 кадров/с`, пресет - `Очень медленно`.

- Установленный флажок `Пользовательские настройки` даёт доступ к настройкам `разрешения экрана`, `битрейта`, `частоты кадров`, `скорости кодировки` и `аппаратному ускорению`. 
- Для изменения разрешения экрана, необходимо установить флажок `Изменить разрешение`.

- Флажок `Использовать видеокарту` изменяет кодек с `libx264` на `h264-nvenc`, поэтому убедитесь что ваш графический ускоритель поддерживает кодировщик `NVENC`.  



## Собранный exe

Собранный `.exe` файл не требует для работы никаких зависимостей.

## Что в проекте

- `main.py` — основной исполняемый модуль приложения.
- `GUI.py` — UI-класс `Ui_Window`.
- `icon.ico` — иконка приложения и окна.

## Что требуется для работы с исходниками

- Python 3.8+
- `PyQt5`
- `ffmpeg-python`
- Установленный и добавленный в PATH `FFmpeg`

## Установка зависимостей

Windows:
- `pip install pyqt5 ffmpeg-python pyinstaller`

## Самостоятельная сборка в один exe

Сборка вместе с иконкой и `ffmpeg.exe` с помощью PyInstaller:
- `pyinstaller --onefile --windowed --add-binary "ffmpeg.exe;." -i icon.ico --add-data "icon.ico;." main.py`


## Как это работает

- Программа использует PyQt5 для GUI.
- `main.py` формирует команду FFmpeg и запускает `ffmpeg.exe` через `subprocess`.
- При ошибке FFmpeg логируется в файл `ffmpeg_error_YYYY-MM-DD_HH-MM-SS.log`.
